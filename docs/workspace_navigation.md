# 일반 생성과 스타일 구성

일반 생성(`/`)과 스타일 구성(`/style`)은 같은 Comfy Home의 두 작업 공간입니다. 상단의 `일반 생성 / 스타일 구성` 토글을 현재 창에서 사용하며, 같은 브랜드·상단 바·좌측 메뉴 규격과 모바일 하단 메뉴를 유지합니다. 스타일의 배경·Panel·입력·버튼은 일반 생성의 색상과 서체를 따릅니다. 각 작업 공간의 메뉴와 본문은 해당 기능에 맞게 표시합니다.

두 작업 공간은 기존 `home_session`과 `/api/login`, `/api/session`, `/api/logout`을 함께 사용합니다. 스타일에 직접 접속해도 인증이 필요하면 기존 일반 생성 로그인 화면 하나를 사용하고, 로그인 후 원래 스타일 화면으로 돌아갑니다. 별도 스타일 비밀번호 입력 화면은 제공하지 않습니다. 복귀 주소는 같은 사이트의 `/style` 또는 `/style-preview`만 허용합니다.

전환은 기존처럼 Document 이동을 사용합니다. 일반 생성의 Prompt·Negative Prompt·LoRA·태그 선택·생성 옵션은 기존 탭별 임시 보관을 통해 복원하고, 스타일의 프로젝트 선택·설정 초안·현재 화면도 유지합니다. 전환이나 스타일 새로고침만으로 저장·생성을 제출하지 않습니다. 스타일의 `새로고침`은 서버 목록을 다시 읽으며 미저장 설정 초안은 유지합니다. 일반 생성의 Form·결과물·작업 관리 UI는 변경하지 않습니다.

공통 자산은 `web/workspace-shell.css`와 `web/workspace-shell.js`입니다. 일반 생성에서는 전환 토글과 로그인 후 복귀만 연결하며, 스타일의 외곽 레이아웃은 공통 CSS에 별도 범위로 정의합니다. 두 자산은 로그인 전에도 제공하고 기존 화면 갱신용 Asset version에 포함합니다.

검증은 임시 DB와 Fake ComfyUI를 사용합니다. `tests/test_workspace_authentication.py`는 Session 공유·만료·Logout과 공통 자산을, `tests/browser_workspace_shell.cjs`는 공통 로그인·두 작업 공간의 모양·초안 왕복·320/390/1280px 레이아웃·의도하지 않은 생성 요청이 없음을 확인합니다. 기존 일반 생성 내비게이션과 스타일 프로젝트·선별·그림체 목록 Browser 검증도 함께 유지합니다.
