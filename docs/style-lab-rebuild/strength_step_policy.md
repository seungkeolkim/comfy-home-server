# 신규 조합의 STR 0.05 배수 규칙

2026-11-16 사용자 요청으로 초기 Random 조합과 다음 세대 후보의 작가 태그·LoRA STR을 0.05 배수로 제한합니다.

## 선택 방법

- Random은 프로젝트별 최소·최대 STR 안에 있는 **0 기준의 0.05 배수** 중 균등 추첨합니다. 최소값에 0.05씩 더하는 방식이 아닙니다.
- 예: `0.23~0.37`은 `0.25 / 0.30 / 0.35`, `-0.123~-0.002`는 `-0.10 / -0.05`, `0.4~0.4`는 `0.4`입니다.
- 범위에 배수가 없는 `0.41~0.44`, `0.33~0.33` 등은 성분 이름과 범위를 표시하는 422 오류로 처리합니다. 범위를 벗어난 값이나 배수가 아닌 끝점을 대신 쓰지 않으며 계획·작업을 저장하지 않습니다. 비활성 성분과 최대 사용 개수가 0인 종류는 이 검사에서 제외합니다.
- 진화의 Mutate·Crossover는 상속·변이 값을 범위 내 가장 가까운 배수로 맞춥니다. 정확히 중간이면 0에서 먼 쪽을 택합니다. Random Mode와 새로 추가하는 성분은 같은 균등 추첨 함수를 사용합니다.
- Decimal로 인덱스 경계를 계산해 음수와 Float 오차로 허용 범위를 벗어나지 않게 합니다. 유효 조합 공간이 줄어 부족해지면 기존 Shortfall·유한 추첨·중복 제외 동작을 사용합니다.
