# Anima Style Lab

Anima(ComfyUI) 작가 태그 조합을 만들고, 둘 중 마음에 드는 쪽을 고르는 것만으로 내 취향의 그림체를 찾아 다듬는 앱입니다.
NAI Style Lab(NovelAI용)의 조합·선별·진화·다듬기 로직은 그대로이고, 그림을 그리는 부분만 ComfyUI의 Anima로 바꿨습니다.

## 준비

필요한 것: Windows 10/11 (Microsoft Edge WebView2 런타임이 들어 있어야 하며, 대부분의 PC에는 이미 있습니다), 실행 중인 ComfyUI. Python은 따로 설치하지 않아도 됩니다.

1. **ComfyUI를 켜 둡니다** (기본 주소 `http://127.0.0.1:8188`). Anima 파일이 들어 있어야 합니다.
   - `models/diffusion_models/` : anima-*.safetensors
   - `models/text_encoders/` : qwen_3_06b_base.safetensors
   - `models/vae/` : qwen_image_vae.safetensors
2. `run.bat`을 더블클릭하면 창이 열립니다. 창을 닫으면 저장 후 자동으로 종료됩니다.
3. **설정 → 연결 · 생성**에서 주소를 확인하고 `연결 확인`을 누르면 ComfyUI에 있는 모델 목록이 뜹니다. Anima 파일 세 개를 고르세요 (이름에 anima / qwen이 들어 있으면 자동으로 골라 줍니다).

이미지 생성 중에 창을 닫으면 진행 중인 생성은 기다리지 않고 멈춥니다(ComfyUI에는 중단 요청을 보냅니다). 그때까지 만든 것은 저장됩니다.

- 데이터: `data/` (state.json, 실행할 때마다 남기는 직전 백업 state.json.bak, images/, 썸네일 캐시 thumbs/, 선택: workflow.json)
- 오류 기록: `data/app.log`

### 프롬프트 변환

앱 안에서는 작가를 `1.2::artist:rurudo ::` 형태로 들고 있다가, 그릴 때 Anima 형식으로 바꿔 ComfyUI에 보냅니다.

| 앱 안 | ComfyUI로 가는 것 |
|---|---|
| `1.2::artist:rurudo ::` | `(@rurudo:1.2)` |
| `1.0::artist:shigure_ui ::` | `@shigure ui` |
| `artist:channel_(caststation)` | `@channel \(caststation\)` |

작가 붙여 넣기 / 자유 생성 / 프롬프트 뷰어에서는 `artist:이름`, `@이름`, `(@이름:1.2)` 모두 읽습니다.
기본 프롬프트는 Anima 권장 순서(품질·안전 → 인원수 → 캐릭터 → 작가 → 나머지)입니다. 캐릭터는 기본 프롬프트에 함께 쓰세요. Anima의 가중치는 SDXL보다 크게 줘야 효과가 보이니, 작가 조합 규칙(조합)의 가중치 범위를 필요하면 넓혀 보세요.

### LoRA 조합

**LoRA Manager 연동:** ComfyUI에 ComfyUI-LoRA-Manager가 설치돼 있으면 'LoRA 추가'와 '트리거 읽기' 때 LoRA Manager가 가진 트리거 단어(Civitai 학습 단어 + 직접 입력한 단어)를 자동으로 가져와 트리거 칸에 채웁니다. 이미 입력한 트리거는 덮어쓰지 않습니다.

그림체 LoRA도 작가 태그처럼 등록해 두면 무작위 조합에 섞입니다.

1. **조합 → LoRA 탭 → ComfyUI에서 불러오기**로 ComfyUI의 `loras` 폴더에 있는 LoRA를 체크해 등록합니다 (ComfyUI 연결이 확인되어 있어야 목록이 뜹니다. 목록에 없으면 파일 이름을 직접 적어도 됩니다).
2. **조합당 LoRA 수**(기본 0~2)와 **기본 가중치 범위**(기본 0.4~1.0)를 정합니다. LoRA를 고르고 `범위 · 트리거 수정`을 누르면 그 LoRA만의 가중치 범위(비우면 기본 범위)와 트리거 단어(조합에 들어가면 프롬프트의 작가 자리 뒤에 붙음)를 정할 수 있습니다.
3. 무작위 조합은 위 개수 안에서 LoRA를 무작위로 고르고 각자의 범위에서 가중치를 뽑습니다. **진화**에서는 작가와 같은 방식(바꾸기·섞기·완전 무작위)으로 LoRA도 함께 섞이고 바뀝니다. **다듬기**에서는 작가와 함께 LoRA 가중치도 움직이되 각 LoRA의 범위를 벗어나지 않습니다.
4. 조합 안에서는 `0.7::lora:anima\foo.safetensors ::`처럼 저장되고, 화면에서는 `LoRA` 표시가 붙은 이름으로 보입니다. LoRA는 프롬프트 글자가 아니라 ComfyUI 워크플로의 LoraLoader 노드로 들어갑니다. 기본은 모델에만 적용(`LoraLoaderModelOnly`)이고, 설정 → 이미지 생성에서 텍스트 인코더에도 적용하도록 바꿀 수 있습니다. `data/workflow.json`을 쓰는 경우에는 샘플러의 모델(옵션으로 CLIP) 바로 앞에 LoRA 노드가 이어집니다.
5. LoRA 점수·사용·승률은 작가 표와 같은 방식으로 계산됩니다.

6. **트리거 자동 읽기**: 등록할 때 ComfyUI를 통해 LoRA 파일 안의 정보를 읽습니다. 파일에 트리거 구절(`modelspec.trigger_phrase`)이 있으면 트리거 칸에 바로 채우고, 학습 때 많이 쓰인 태그는 `범위 · 트리거 수정` 창에 후보로 나옵니다(눌러서 추가). 이미 등록한 LoRA는 선택 후 `트리거 읽기`로 다시 읽습니다. 직접 적어 둔 트리거는 덮어쓰지 않습니다. 파일에 학습 정보가 없으면 후보가 비어 있으니 배포 페이지의 트리거를 직접 적으세요.
7. **호환 경고**: 파일 정보에 SD1.5 / SDXL(Illustrious, NoobAI 포함) 기반으로 적혀 있으면 표에 `⚠ 호환 안 됨`이 뜹니다. 그런 LoRA는 Anima에서 적용되지 않습니다(ComfyUI 로그의 `lora key not loaded`).

   트리거를 못 읽는 경우: 파일에 메타데이터가 아예 없으면(Anima LoRA를 만드는 트레이너 중에는 이렇게 저장하는 곳이 많습니다) ComfyUI가 정보를 주지 못해 읽을 수 없습니다. 이때는 화면에 이유가 뜨고 `data/lora_meta.log`에 파일마다 어떤 정보가 있었는지 남습니다. 폴더 이름(`10_이름`)이나 태그 목록처럼 트리거로 쓸 만한 정보가 있으면 후보로 올립니다.
8. **로드 실패 기록**: LoRA가 든 그림을 그릴 때마다 ComfyUI의 로그(`/internal/logs/raw`)에서 `lora key not loaded` 경고를 확인합니다. 경고가 나오면 `data/lora_warnings.log`에 시각·시드·조합·모델·붙이지 못한 키 개수와 키 이름 유형·예시를 남기고, 한 LoRA만 든 그림이면 그 LoRA에 `⚠ 로드 실패`를 표시합니다(경고 없이 그려지면 표시가 사라짐). 여러 LoRA가 함께 든 그림은 어느 쪽 문제인지 알 수 없어 기록에 전부 적습니다. ComfyUI가 로그를 보관하는 줄 수(약 300줄)에 한계가 있어 키 개수는 그 이상이면 일부만 보입니다. 로그를 못 읽는 오래된 ComfyUI에서는 이 기능만 조용히 빠집니다.

작가 없이 LoRA만 쓰고 싶으면 조합 탭에서 작가 쪽의 **켜짐** 스위치를 눌러 끄세요(꺼진 쪽은 회색으로 바뀌고, 설정한 범위는 그대로 보관됩니다). 반대로 LoRA를 끌 수도 있습니다. 둘 다 끌 수는 없습니다.

LoRA 파일 이름에 쉼표(`,`)나 `::`가 들어 있으면 조합 문자열이 깨지므로 등록되지 않습니다. 이름을 바꿔 쓰세요. 데이터 형식이 2로 올라가서, 이 버전이 저장한 데이터는 5.0 이전 앱에서 열리지 않습니다(처음 실행할 때 기존 데이터는 그대로 올려 줍니다).

### 내 워크플로 쓰기 (선택)

기본은 ComfyUI 표준 노드(UNETLoader · CLIPLoader `stable_diffusion` · VAELoader · KSampler)로 만든 내장 워크플로입니다. LoRA, 다른 스케줄러(beta57 등), 모델 샘플링 노드 같은 걸 쓰고 싶으면:

1. ComfyUI에서 내 워크플로가 잘 돌아가는 걸 확인하고 **Save (API Format)** 으로 저장합니다 (보이지 않으면 ComfyUI 설정에서 Dev mode를 켜세요).
2. 그 파일을 `data/workflow.json` 으로 넣습니다. 지우면 내장 워크플로로 돌아갑니다.

앱은 이 워크플로의 긍정/부정 프롬프트 칸, 시드, 가로세로, Steps, CFG, 샘플러, 스케줄러만 채우고(샘플러·스케줄러 설정이 비어 있으면 워크플로 값 그대로) 나머지는 건드리지 않습니다. 프롬프트가 다른 노드에서 들어오는 구조거나 끝에 PreviewImage/SaveImage가 없으면 알려 줍니다.

| ③ 진화 | 지금의 상위 30%(S·A) 조합들의 작가와 가중치를 섞고 바꿔 새 조합을 만들고, 선별로 상위 30% 사이 어디쯤인지 찾습니다. 그중 가장 낮은 조합에게도 지면 탈락, 이기면 살아남고 그 수만큼 기존 최하위가 제외됩니다. 전체 조합 수는 유지됩니다. | 진화 · 선별 |
| ④ 다듬기 | 고른 조합의 작가·LoRA 가중치(바꿀 대상은 전체 / 작가만 / LoRA만 선택)를 크고 작게 바꾼 변형을 수십 장 그려 선별합니다. 이긴 변형들의 LoRA 값이 가장 가깝게 겹치는 곳을 추천 값으로 알려 주고, 추천 값으로 그림을 그려 볼 수 있습니다. | 다듬기 · 선별 |
| ⑤ 완성 | 추천 값으로 그린 그림 중 마음에 드는 것을 북마크하며 목록에 넣습니다. | 다듬기 |

### 선별의 자동 모드

선별 화면은 기본적으로 자동 모드입니다. 지금 필요한 선별을 우선순위대로 골라 줍니다.

0. 진행 중인 다듬기가 있으면 그 변형 선별이 모든 모드에서 가장 먼저 나옵니다. (변형의 가중치는 가려져 나옵니다.)
1. 새 조합 자리 찾기. 평가된 조합이 24개가 되기 전에는 새 조합끼리 붙이고(한 번 투표로 둘 다 평가됨), 그 뒤에는 순위표의 조합과 비교해 자리를 찾습니다.
2. 상위 30% 경계에서 점수가 같은 조합이 6개 이하일 때만 그 동점을 가립니다(`전체 리그`·`상위 30%` 모드에서는 가장 먼저). 같은 점수가 그보다 많으면 승률, 선별 수, 오래된 순으로 순위를 정해 진화를 막지 않습니다. 상위 30% 안쪽의 동점은 진화를 막지 않고 일반 선별에서 풀립니다.
3. 진화 조합 평가 (만드는 중에는 이미 만들어진 조합의 자리 찾기만, 검증 선별은 다 만든 뒤)
4. 다듬기 변형 선별
5. 할 일이 없으면 일반 리그로 순위 결정

`전체 리그`와 `상위 30%` 모드는 순위만 더 다듬고 싶을 때 씁니다.

### 단축키

`←` / `→` (숫자 패드 `4` / `6`) 고르기 · `Enter` 비슷함(건너뛰기) · `Backspace` 되돌리기(여러 번 가능) · 휠 확대 · 드래그 이동 (그림체 목록·다듬기·자유 생성에서는 이미지 클릭으로 크게 보기). 원본은 이미지 옆 원본 열기 버튼으로 엽니다.
선별의 확대·이동은 양쪽 그림에 함께 적용되어 같은 부분을 나란히 비교할 수 있습니다. 두 그림이 다 뜨기 전에는 고를 수 없고, 키를 누르고 있어도 한 표만 들어갑니다.
그림체 목록과 작가 표에서는 클릭 선택(다시 클릭하면 해제), `Shift`/`Ctrl` 다중 선택, `Delete` 삭제, `Ctrl+A` 전체 선택, `Esc` 선택 해제.

### 그 밖의 기능

- **프롬프트 뷰어**: ComfyUI로 만든 PNG(메타데이터가 남아 있는 원본)를 앱 창에 끌어다 놓으면 프롬프트·네거티브·설정을 보여 주고, 그림에 쓰인 작가(`@이름`)를 한 번에 등록할 수 있습니다. 네거티브의 작가와 음수 가중치 작가는 등록하지 않습니다.

## 규칙

- **시드 하나로 모든 그림을 그립니다.** 설정의 시드가 비어 있으면 첫 생성 때 무작위로 정해 저장합니다.
- **같은 그림 다시 뽑기**: 시드·크기·Steps·CFG·샘플러·프롬프트가 같으면 같은 ComfyUI·같은 모델에서 같은 그림이 나옵니다. 그림 PNG에는 ComfyUI 워크플로가 들어 있어 ComfyUI에 끌어다 놓으면 그대로 다시 열립니다.
- **조합 규칙**(조합당 작가 수, 가중치 범위)은 조합에서 바꾸며, 무작위 조합·진화 조합·다듬기 변형 모두에 적용됩니다. 예전 설정으로 만든 조합에서 가져온 값도 범위 안으로 맞춥니다.
- **진화 조합 만들기**: 상위 30% 조합 하나의 작가 1~3명 교체·삭제·추가(가중치 ±0.3), 상위 30% 조합 둘 섞기, 완전 무작위를 1/3씩. 부모는 순위가 높을수록 잘 뽑힙니다(1위가 꼴찌의 2배). 새로 뽑는 작가는 지금 상위 30%에 적게 쓰인 작가일수록, 그리고 작가 점수가 높을수록 잘 뽑힙니다(최고 점수 작가가 평균의 2배, 최저는 0.5배, 기록이 없는 작가는 평균). 진화 기록에 방식과 부모를 남깁니다.
- **투표가 모순될 때**(윗 순위는 이기고 아랫 순위에는 짐) 어긋나는 표가 가장 적은 자리로 배치하고, 합격선 근처는 검증 선별을 더 합니다.
- **탐색 종료 신호**: 2세대 연속으로 살아남은 진화 조합이 없으면 다듬기로 넘어가라고 안내합니다.
- **최종 확인**에서 챔피언이 원본 그대로면 원본만 다른 시드로 한 번씩 그립니다. 중간에 멈추면 라운드 결과 화면으로 돌아갑니다.
