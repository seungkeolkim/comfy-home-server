## 접속과 확인 순서

- 현재 Home 주소의 `/style-preview#project-settings`에서 시작합니다. PC는 `http://localhost:8388/style-preview#project-settings`입니다.
- Desktop은 왼쪽 `프로젝트 설정`·`글로벌 설정` 메뉴를 사용합니다.
- Mobile은 하단 `설정`으로 들어가 상단의 두 설정 탭을 사용합니다.
- 상단 현재 프로젝트는 설정의 작업 대상입니다. 그림체 탭의 프로젝트 선택 UI는 이전 요청대로 변경하지 않았습니다.

1. **프로젝트 설정**에서 메모·Prompt·공통 Negative를 작성하고 작가 태그·LoRA 구역에서 성분별 사용 여부·STR 범위를 조정합니다. 같은 강도를 쓰려면 `0.4 ~ 0.4`처럼 최소·최대를 같게 입력합니다. `이 탭의 예시에 반영`을 누릅니다.
2. 다른 프로젝트로 바꿔 설정이 섞이지 않는지 확인하고 원래 프로젝트로 돌아옵니다. 반영 전 입력 초안도 프로젝트별로 유지됩니다.
3. **글로벌 설정**에서 작가나 LoRA의 기본 STR 범위를 바꾸고 반영합니다. Pipeline과 분리된 두 성분 구역의 배치도 확인합니다. ComfyUI 연결은 Home 설정을 공유하며 별도 주소·Port 입력은 없습니다.
4. 프로젝트 설정으로 돌아와 기존 범위가 유지되는지 확인합니다. `최신 STR 기본값 가져오기`를 눌러 변경 전후를 보고 취소하거나 해당 프로젝트의 초안에 적용합니다. 적용한 초안은 별도로 반영합니다.

확인받을 내용은 세 가지입니다.

- 글로벌과 프로젝트 설정이 분리된 위치를 이해하기 쉬운가요?
- Prompt와 종류별 성분 사용 여부·STR 범위를 이 화면에서 정하는 흐름이 편한가요?
- 글로벌 기본값을 기존 프로젝트에 가져오기 전에 변경 내용을 확인하는 방식이 적절한가요?

프로젝트 성분 사용 여부는 기존 차이 보기의 제외·재허용과 동기화합니다. 전용 STR 고정 체크박스·고정값 입력은 제거했습니다. 기본값 가져오기는 STR 범위만 바꾸며 Prompt·Workflow·성분 사용 여부는 유지합니다. 최소=최대인 범위도 명시적으로 가져오는 새 기본값으로 교체되며 변경 전후에 표시합니다. 최소가 최대보다 큰 범위는 반영을 거부합니다.

성분별 이름·사용 여부와 STR 입력은 여러 줄로 유지합니다. 고정값을 제거한 오른쪽 여유 공간은 그대로 두며 향후 사용 횟수·선호 점수 등의 정보에 사용할 수 있습니다. 이번에는 이 통계를 임의로 만들어 표시하지 않습니다.

기존 목업 Session에서 STR 고정을 사용했다면 해당 값을 최소=최대로 변환하고 전용 필드를 제거합니다. 프로젝트·Prompt·초안은 보존하며 과거 별도 Endpoint·실행기 예시 값은 더 이상 사용하지 않습니다.

### 작가 태그 일괄 등록 목업

접속 후 **글로벌 설정 → 작가 태그 → 작가 태그 일괄 등록**을 사용합니다. 이름을 한 줄씩 붙여 넣으면 신규·기등록·입력 중복·확인 필요 줄을 즉시 구분합니다. `신규 작가 N명 등록`을 누르면 탭의 글로벌 Catalog에 바로 등록하며, 별도의 설정 반영 버튼을 다시 누를 필요가 없습니다. 다른 글로벌 설정의 미반영 초안은 유지합니다.

```text
necomi
artist:shigure_ui
@absolute \(queen\)
```

- Style Lab의 정리 규칙을 참고해 `artist:`·`@` 접두어와 Backslash Escape를 정리하고 공백은 `_`로 바꿉니다. 위 입력은 `artist:necomi`, `artist:shigure_ui`, `artist:absolute_(queen)`로 등록됩니다.
- 빈 줄은 건너뛰고, 정리한 태그를 기준으로 기등록·입력 내 중복을 제외합니다. 대소문자는 임의로 바꾸지 않으며 신규 작가는 처음 등장한 순서를 유지합니다.
- 원본 Style Lab은 쉼표 목록·Prompt 전체의 작가 추출도 지원합니다. 이번 목업은 요청한 **줄 단위 명단 등록**으로 한정합니다. 쉼표 목록·가중치·Prompt 문법이나 숫자뿐인 줄은 확인 필요로 표시하고 등록하지 않습니다.
- 유효한 신규 작가만 등록합니다. 확인 필요 줄은 입력창에 남겨 수정할 수 있습니다. 미리보기는 앞 20줄로 제한하되, 등록 버튼의 전체 신규 수를 기준으로 전부 등록합니다.
- 기존 프로젝트와 작성 중 초안에는 신규 성분을 미선택 상태로 보충합니다. 프로젝트 설정의 작가 구역에서 직접 사용을 켜고 STR 범위를 정합니다. 기존 성분·선택·Prompt·후보 조합은 바꾸지 않습니다.
- 이후 만드는 새 프로젝트는 등록된 글로벌 Catalog의 사용 여부·기본 STR 범위를 복사합니다. 등록 목록·입력 초안은 같은 탭의 새로고침·화면 전환 후 복구합니다.
- 작가 등록은 목업의 Session Storage에만 반영하며 실제 Style Lab·Home DB·작가 점수·생성 작업에는 쓰지 않습니다.

### Workflow 옵션 구성

사용자 추가 피드백에 따라 글로벌 설정의 `Home과 함께 쓰는 실행 환경` 안내 Panel도 제거했습니다. 연결 설정 공유는 내부 구현 계약으로 유지하며, 사용자 화면에 반복 안내하거나 별도 입력을 받지 않습니다.

프로젝트의 `Workflow와 생성 조건`은 **Workflow 옵션**으로 바꾸고 현재 CHS 이미지 Workflow의 항목·순서·입력 동작을 따릅니다.

1. Workflow 선택
2. 비율 / 해상도
3. 너비 / 높이
4. Steps / CFG

Desktop·Mobile 모두 각 입력 쌍을 두 칸으로 배치합니다. 비율별 해상도 목록은 `web/workflow-options.js`에서 일반 생성과 공유합니다. 사용자 지정에서는 해상도 선택을 비활성화하고 너비·높이를 직접 입력하며, 나머지 비율에서는 선택한 해상도가 너비·높이에 반영됩니다. 목업에만 있던 Seed 입력과 접힌 상세 영역은 제거했습니다. 비교에 필요한 내부 Seed 값은 보존하며 실제 Seed 정책은 생성 단계에서 연결합니다.

새 프로젝트의 초기값은 현재 CHS 초기 화면과 같은 2:3·576×864·Steps 12·CFG 1입니다. 기존 프로젝트의 크기·Steps·CFG는 보존합니다. 기존 크기가 공통 해상도 후보에 있으면 해당 비율을 선택하고, 후보 밖의 크기는 사용자 지정으로 복구합니다. 이전 `guidanceScale` 값은 `cfg`로 옮깁니다. 실제 Workflow·성분 Catalog 연결은 여전히 후속 단계입니다.

글로벌에서 성분을 사용 불가로 바꿔도 기존 프로젝트의 선택을 지우지 않습니다. 해당 성분을 여전히 사용하도록 설정한 프로젝트를 반영하려 하면 충돌을 표시합니다. 새 프로젝트의 초기 사용 여부·STR 범위는 당시 반영된 글로벌 설정을 복사합니다.

## 실제 연결과의 경계

편집하는 값은 **예시 데이터**이며 이 탭의 Session Storage에 임시 보관됩니다. 실제 연결 시 Home의 기존 ComfyUI 설정을 사용하며 스타일 구성 전용 연결값을 만들지 않습니다. 이번 목업에서 Home 연결 설정이나 실제 Workflow·LoRA 파일 Catalog를 변경하지 않습니다. 다른 기기·새 Session에 공유되는 저장 기능은 아직 없습니다.

설정 화면에서 Prompt나 생성 조건을 바꿔도 기존 SVG 예시 결과를 재생성하거나 그 조건의 실제 결과로 표시하지 않습니다. 선별은 원래의 예시 Prompt와 이미지를 사용합니다. 기존 조합의 독립 Model/CLIP Strength·이력·점수도 수정하지 않습니다.

필수 성분 포함·조합별 성분 개수·동적 잠금 정책 전체는 초기 조합 생성 단계에서 구현합니다. 아직 프로젝트 DB·평가 조건 Version·실제 생성·유전 알고리즘을 추가하지 않았습니다. 다음 단계는 이 UI에 대한 사용자 피드백을 받은 뒤 **Fresh 프로젝트 생성·저장·다시 열기**이며, 이번 작업에서 시작하지 않습니다.
