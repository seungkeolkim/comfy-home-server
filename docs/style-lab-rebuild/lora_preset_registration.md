# 그림체에서 CHS LoRA 조합 등록

2026-11-16. 그림체의 조합 보기 옆에서 선택한 LoRA Snapshot을 일반 생성에 쓸 수 있도록 CHS에 등록합니다. 기존 별표 즐겨찾기와 독립적인 등록 기능입니다.

## 사용 흐름

- 그림체·진화 카드의 **조합 보기 / LoRA 조합 등록**을 나란히 표시합니다. 등록 뒤에는 **LoRA 등록 해제**로 바뀝니다. LoRA가 없는 작가 전용 조합은 등록 버튼을 비활성화합니다.
- **LoRA 등록된 것만 보기**는 현재 프로젝트의 모든 평가 조건·세대·퇴역 상태에서 등록본을 모읍니다. 별표 필터를 함께 켜면 교집합입니다. 프로젝트별 선택을 Browser Session에 보관하고, 해제하면 원래 상태 필터로 복귀합니다. 새 후보 생성 시 두 모아보기를 해제해 새 이미지를 표시합니다.
- CHS의 **LoRA 조합**에서 **스타일 구성 · 자동 등록** 배지, 프로젝트별 묶음, 원본 모델·세대·조합번호를 표시합니다. 등록본 필터와 전체 이름·프로젝트·모델·LoRA 검색을 제공합니다. 일반 조합의 편집·복제·삭제·생성 적용은 기존 경로를 사용합니다.
- 등록 이름은 `[스타일] {전체 프로젝트명} · 세대003-조합35` 형식입니다. 프로젝트명 최대 80자와 preset 이름 최대 120자 범위에서 전체 이름을 저장합니다. 목록 제목만 말줄임하고 세대·조합번호는 별도 줄에 유지합니다. 생성 Select는 프로젝트명 앞 12자와 번호를 표시하며, 편집 상세에는 전체 이름과 원본 모델을 표시합니다.
- **원본 그림체**는 프로젝트와 원본 카드로 이동합니다. 퇴역도 표시할 수 있도록 해당 이동에서만 필터 범위를 설정합니다. URL의 원본 이동 인자는 한 번 소비하고, 이후 새로고침에서는 Session에 저장한 필터를 유지합니다. 삭제된 원본은 링크 대신 삭제 상태만 표시합니다.

## 저장·수명 경계

- LoRA 파일명·STR·CLIP을 생성된 원본 조합에서 읽고 기존 `lora_presets`에 저장합니다. 생략한 CLIP은 원본 생성 경로와 같이 STR을 따르며 명시적인 독립 CLIP 0도 보존합니다. 현재 프로젝트 설정이나 개별 LoRA 기본값으로 덮지 않습니다. 작가 태그·Prompt·이미지·Elo는 이 preset에 포함하지 않습니다.
- 등록본은 독립 Snapshot입니다. 퇴역·원본 폐기 뒤에도 계속 사용할 수 있습니다. CHS에서 강도를 바꾸면 **원본에서 수정됨**을 표시합니다. 다시 등록 명령을 보내도 이미 저장한 편집본을 원본으로 덮어쓰지 않습니다. 복제는 출처 연결이 없는 일반 preset입니다.
- 프로젝트 Rename은 같은 DB Transaction에서 출처의 프로젝트명을 갱신합니다. 자동 생성한 preset 이름만 같이 바꾸고 사용자가 직접 붙인 이름은 유지합니다.
- 등록 해제는 연결된 CHS preset만 삭제합니다. 원본 그림체·별표·투표·이미지를 삭제하지 않습니다. CHS에서 preset을 직접 삭제해도 등록 정보가 정리되고 스타일 결과 Polling에 반영됩니다.

## 구현 계약

- `PUT /api/style-projects/{projectIdentifier}/candidates/{candidateIdentifier}/lora-preset`, Body `{"isRegistered": true}` 또는 `false`. 인증·소유 프로젝트·제출된 조합·삭제 상태를 검사합니다. 잘못된 소유·미제출·폐기 원본은 404, LoRA 없음·엄격한 Bool 위반·추가 필드는 422입니다.
- 같은 후보에는 하나의 preset만 연결합니다. SQLite `BEGIN IMMEDIATE`와 후보 ID Unique Key, 기존 생성 Mutation Lock으로 중복 등록·Rename·원본 폐기 경합을 처리합니다. 응답 유실 뒤 같은 등록 여부를 다시 보내도 중복 생성하거나 상태를 뒤집지 않습니다.
- Schema **20**의 `style_lora_preset_sources`는 preset ID, 원본 후보·프로젝트·평가 ID, 전체 프로젝트명, 세대·조합번호, 원본 모델, 자동 이름, 원래 LoRA Snapshot을 보관합니다. preset FK만 `ON DELETE CASCADE`이며 원본에 삭제 Cascade를 두지 않습니다. Schema 19는 검증된 원본 Backup 후 테이블·Index를 추가합니다.
- Generation Results Summary·전체 결과에 nullable `loraPresetIdentifier`를 추가합니다. 기존 후보 일괄 SQL의 Join으로 조회하며 파일 접근이나 후보별 추가 요청을 하지 않습니다. CHS preset 목록의 `style_source`는 출처·원본 이동 가능 여부·수정 여부를 일괄 조회합니다.
- 등록 중 해당 버튼만 잠그고 프로젝트 이동은 허용합니다. 이전 Polling은 저장 결과를 덮지 못하게 무효화하며 등록 중 새 Polling을 합칩니다. 이미지 DOM·Thumbnail Cache·Viewer를 재사용합니다. CHS 검색·필터·목록 재진입은 미저장 preset 편집값을 지우지 않습니다.
